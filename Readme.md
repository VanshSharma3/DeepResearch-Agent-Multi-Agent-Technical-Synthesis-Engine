# deepresearch-agent

A multi-agent technical research and writing pipeline built with **LangGraph**, **FastAPI**, and a simple frontend dashboard.

I built this project to solve the issue of superficial, hallucinated technical articles generated by single-prompt LLMs. Instead of generating an entire article in one go, this system plans out sections, checks if web research is required, runs parallel workers to draft each section, and stitches everything together into a clean markdown format with real citations.

---

## 📌 How It Works (Pipeline Architecture)

1. **Router**: Analyzes the topic and decides if it needs external web search (`closed_book` vs `hybrid` / `open_book`).
2. **Researcher**: Uses Tavily API to fetch relevant web data, cleans up raw snippets, and deduplicates sources by URL.
3. **Orchestrator**: Breaks down the topic into structured technical sections (3–5 subtopics each) using strict Pydantic schemas.
4. **Parallel Workers (Fan-Out)**: Uses LangGraph's `Send` API to draft individual sections concurrently instead of sequentially.
5. **LLM Fallback**: Runs on Groq (`llama-3.1-8b-instant`) by default for speed, and falls back to Google Gemini (`gemini-1.5-flash`) if Groq hits rate limits or token exhaustion.
6. **Reducer**: Collects all completed sections, preserves the correct order, and generates the final markdown article.

## 🛠️ Tech Stack

- **Orchestration & Agents:** LangGraph, LangChain Core, Pydantic v2
- **LLMs:** Groq (Llama 3.1 8B), Google GenAI (Gemini 1.5 Flash)
- **Web Search:** Tavily API
- **Backend:** FastAPI, Uvicorn
- **Frontend:** Vanilla HTML/CSS/JavaScript, Marked.js

---

## ⚙️ Key Engineering Problems Solved

- **Handling LLM Rate Limits:** Handled Groq TPM rate limits using `.with_fallbacks([gemini_llm])` and shortened search snippet contexts before passing them to the planner.
- **Pydantic Validation Failures:** Fixed edge cases where smaller models output boolean strings (`"true"`) instead of raw JSON booleans by adding a `@field_validator(mode="before")` parser.
- **Organic Citation Linking:** Forced worker prompts to embed actual source URLs directly into natural context sentences rather than appending useless `[Source]` or raw URL dumps.
